# Identification of Differentially Expressed Genes and Key Biomarkers in Alzheimer's Disease using Machine Learning

## Project Overview
This project aims to identify Differentially Expressed Genes (DEGs) and potential biomarkers associated with Alzheimer's Disease using machine learning approaches.

## Methods
- Data Preprocessing
- DEG Analysis
- Random Forest
- Support Vector Machine (SVM)
- Volcano Plot
- Heatmap
- ROC Analysis
- Pathway Enrichment Analysis

## Tools and Libraries
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Results
The study identified significant DEGs and key biomarkers associated with Alzheimer's Disease.
